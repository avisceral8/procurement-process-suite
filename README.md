# Procurement Process Suite

Four interactive BPMN 2.0 process maps rendered with [FlowForge](https://github.com/avisceral8/flowforge) (fork of tt-a1i/archify):

1. **Vendor Onboarding** — registration → sanctions/KYB screening → risk gate → activation
2. **Procure-to-Pay** — MSA → SOW → PR → PO → invoice → 3-way match → payment
3. **Three-Way Match & Invoice Exceptions** — tolerance gate, price/quantity exception routing
4. **RFx Sourcing & Award** — RFP → bids → weighted scoring → negotiation → approval → contract

Open `index.html` for the combined tabbed suite, or any single diagram directly.

Live: https://procure-suite.onrender.com
